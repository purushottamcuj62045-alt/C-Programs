# C Programs Collection

A collection of C programming examples and practice programs written for learning core programming concepts, problem solving, and logic building.

## Topics Covered

- Basic C Programs
- Loops and Conditional Statements
- Functions
- Arrays
- Strings
- Pointers
- Structures
- File Handling
- Pattern Programs
- Sorting and Searching
- Data Structures Basics

## Features

- Beginner-friendly examples
- Simple and clean code
- Helpful for students learning C programming
- Practice programs for college labs and interviews

## Technologies Used

- Language: C
- Compiler: GCC / Turbo C / CodeBlocks

## How to Run

1. Clone this repository

```bash
git clone https://github.com/purushottamcuj62045-alt/C-Programs.git
```

2. Open terminal in project folder

3. Compile the program

```bash
gcc filename.c -o output
```

4. Run the program

```bash
./output
```

## Example

```c
#include<stdio.h>

int main() {
```
